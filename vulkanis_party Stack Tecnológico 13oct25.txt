Stack Tecnológico del Proyecto (Full-Stack)
Backend:
Lenguaje : TypeScript
Framework : NestJS
ORM : TypeORM
Base de Datos : PostgreSQL
Autenticación : JWT (Json Web Token)
Seguridad : Passport.js, Bcrypt
Documentación : Swagger UI
Entorno : Node.js v18+
Frontend Web:
Framework : React
Estilos : CSS / Material UI
Enrutamiento : React Router DOM
HTTP Client : Axios
Estado global : Context API o Zustand / Redux Toolkit (opcional)
Aplicación Móvil:
Framework : React Native
UI Lib : NativeWind o NativeBase
Enrutamiento : React Navigation
HTTP Client : Axios
Notificaciones Push : Firebase Cloud Messaging (FCM) o Expo Notifications
GPS/Ubicación : react-native-location o @react-native-community/geolocation
Streaming ("Ventana Mágica"):
Protocolo : WebRTC
Backend Signal Server : Node.js + Socket.IO
Frontend Streaming : React + react-player o webrtc-streamer
Cliente móvil : React Native + react-native-webrtc
